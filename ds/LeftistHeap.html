    Weight-Biased Leftist Min-Heap Algorithms

    Weight-Biased Leftist Property

    A Weight-Biased Leftist Heap (WBLT) is a mergeable min-heap where every node stores its weight (total number of nodes in its subtree, with weight(null) = 0). For every node, the left subtree is at least as heavy as the right subtree:

    weight(left) ≥ weight(right)

    Consequently, the rightmost path from any node of size n has length at most ⌊log2(n + 1)⌋.

    Operations

    • Minimum: O(1) — Always at the root.
    • Merge(H1, H2): O(log n) — Traverses down the rightmost spine choosing the smaller root (leaving its right child unassigned as a dashed line while recursing). While unwinding recursion, updates weights and swaps left/right children whenever weight(left) < weight(right).
    • Insert: O(log n) — Merges a 1-node heap with the existing heap.
    • Delete Min: O(log n) — Removes the root and merges its left and right subtrees.

    Build Algorithms

    • Build Random (Sequential): O(n log n) — Inserts elements one by one.
    • Build Bottom-Up (Pairwise): O(n) — Places single-node heaps in a queue, repeatedly merges the front two, and enqueues the result.

    Tips & Keyboard Shortcuts

    • Implementation View: Toggle the Implementation checkbox to inspect the internal memory-structure diagram (external value box referenced by a purple pointer cell, yellow weight, light-blue left/right pointer cells, and root reference).
    • Batch Insert: Enter comma-separated numbers (e.g., 40, 15, 30, 5, 22).
    • Mouse / Touch: Drag to pan, scroll wheel or pinch to zoom, click/tap a node to copy its value, hover to highlight its subtree and inspect weights and leftist balance status.
    • Shortcuts: Enter Insert, Space Pause/Resume, ←/→ Step Back/Forward, Ctrl+Z Undo, Esc Close Help.
