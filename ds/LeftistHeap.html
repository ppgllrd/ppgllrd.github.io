    Weight-Biased Leftist Min-Heap (WBLH)

    Properties

    A binary tree where every node satisfies:

    • Min-Heap Property: Each parent's key is ≤ its children's keys.
    • Weight-Biased Leftist Property: weight(left) ≥ weight(right), where weight is the number of nodes in the subtree. Consequently, the right spine has length ≤ log2(n + 1).

    Operations

    • Minimum: O(1) — Always at the root.
    • Merge(H1, H2): O(log n) — Traverses down the rightmost spine choosing the smaller root. While unwinding recursion, updates weights and swaps left/right children whenever weight(left) < weight(right).
    • Insert: O(log n) — Merges a 1-node heap with the existing heap.
    • Delete Min: O(log n) — Removes the root and merges its left and right subtrees.

    Build Algorithms

    • Build Random (Sequential): O(n log n) — Inserts elements one by one.
    • Build Bottom-Up (Pairwise): O(n) — Places 1-node heaps in a queue, repeatedly merges the front pair, and enqueues the result.

    Tips & Keyboard Shortcuts

    • Batch Insert: Enter comma-separated numbers (e.g., 40, 15, 30, 5, 22).
    • Mouse / Touch: Drag to pan, scroll wheel or pinch to zoom, click a node to copy its value, hover to inspect weights and leftist invariant.
    • Shortcuts: Enter Insert, Space Pause/Resume, ←/→ Step Back/Forward, Ctrl+Z Undo, Esc Close Help.
