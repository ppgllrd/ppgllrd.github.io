    Linear Probing Hash Table

    Concept

    An open addressing strategy where collisions are resolved by probing linearly: (index + 1) % keys.length. All keys belonging to a probe sequence form a contiguous cluster terminated by a null cell. Displaced keys display a badge h:home (+dist) indicating their home hash index and probe distance.

    Operations & Complexity (aligned with Java)

    • Insert O(1) avg — First checks loadFactor() > maxLoadFactor (rehashing to next prime > 2 * capacity if exceeded, O(n)). Then calls searchIndex(key): if an empty slot is found, inserts and increments size; if the key already exists, updates keys[index] = key (amber highlight).
    • Search O(1) avg — Probes from hash(key) until the key is found (Hit) or a null slot is encountered (Miss).
    • Delete (Rehash Cluster — default) O(1) avg — Mode that clears and re-inserts every subsequent key in the cluster.
    • Delete (Backward Shift) — Alternative that empties the found slot (hole) and scans forward in the cluster. The first key whose probeDistance(hash, hole) < probeDistance(hash, current) is shifted back into the hole, repeating until a null cell is reached.

    Tips & Keyboard Shortcuts

    • Batch Insert / Delete: Enter comma-separated keys (e.g., A, B, 42, cat).
    • Shortcuts: Enter Insert, Space Pause/Resume, ←/→ Step Back/Forward, Ctrl+Z Undo, Esc Close Help.
