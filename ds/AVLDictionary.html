    AVLDictionary<K, V>: Algorithms & Controls

    AVLDictionary Overview

    AVLDictionary<K, V> implements a SortedDictionary backed by a self-balancing AVL search tree storing Entry<K, V> pairs ordered by their unique key.

    Balance Factor (BF) = Height(Left) − Height(Right). Valid values are in {-1, 0, 1}. Inserting an existing key updates its mapped value in-place.

    Time Complexity

    • insert(entry): O(log n)
    • delete(key): O(log n)
    • valueOf(key) / isDefinedAt(key): O(log n)
    • minimum() / maximum(): O(log n)
    • keys() / values() / entries(): O(n)

    Implementation View

    Toggle the Implementation checkbox to inspect the internal memory layout of each AVL node as a 4-cell horizontal strip:

    • Purple cell (elem): pointer referencing an external two-field Entry<K, V> object (key in green, value in amber).
    • Yellow cell (height): height of the subtree rooted at this node.
    • Light-blue cells (left / right): child pointers (a blue dot without an arrow indicates null), together with the top root reference box.

    AVL Rotations

    • Right Rotation (LL): Left child moves up, pivot moves down right.
    • Left Rotation (RR): Right child moves up, pivot moves down left.
    • Left-Right (LR): Left child rotates left, then pivot rotates right.
    • Right-Left (RL): Right child rotates right, then pivot rotates left.

    Tips & Keyboard Shortcuts

    • Batch Insert: Enter comma-separated key:value pairs in the Key input (e.g., 30:sun, 10:sea, 50:sky, 20:star) and click insert.
    • Batch Delete: Enter comma-separated keys (e.g., 10, 30) and click delete.
    • Mouse / Touch: Drag to pan, scroll wheel or pinch to zoom, click/tap a node to copy its key & value, hover to highlight its subtree and inspect Balance Factor & metrics.
    • Shortcuts: Enter Insert, Space Pause/Resume, ←/→ Step Back/Forward, Ctrl+Z Undo, Esc Close Help.
