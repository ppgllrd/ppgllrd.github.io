    SortedLinkedSet

    A SortedLinkedSet stores unique elements in ascending order as a singly linked chain of node objects (element and next). The set object keeps first and size.

    When no active reference can reach a node object, it becomes an unreachable object and may be reclaimed by the Java garbage collector (crossed in red).

    Finder, Builder, and Iterator

    Finder searches linearly and reports previous, current, and found.

    Builder maintains first, last, and size for O(1) append during Union, Intersection, and Difference.

    Iterator keeps a current reference advancing node-by-node until null.

    Complexity

    • Insert / Delete / Contains: O(n)
    • Iterate: O(n)
    • Clear / Empty: O(1)
    • Union / Intersection / Difference: O(n + m)

    Tips & Keyboard Shortcuts

    • Batch Insert / Delete: Enter comma-separated integers in Element (e.g., 5, 12, 20).
    • Shortcuts: Enter Insert, Space Pause/Resume, ←/→ Step Back/Forward, Ctrl+Z Undo, Esc Close Help.
