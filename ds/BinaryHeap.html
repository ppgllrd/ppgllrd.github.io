    Binary Min-Heap

    Properties

    A complete binary tree where every node satisfies the Min-Heap property: each parent's key is less than or equal to its children's keys. The minimum is always at the root.

    Operations

    • Get Minimum: O(1) — Directly at index 0.
    • Insert: O(log n) — Append at the end and "bubble up" (sift up) while smaller than parent.
    • Delete Min: O(log n) — Remove root, move last element to index 0, and "bubble down" (sift down).

    Array Mapping

    Stored contiguously level-by-level without pointers:

    • Root: index 0
    • Left Child of i: 2*i + 1
    • Right Child of i: 2*i + 2
    • Parent of i: ⌊(i - 1) / 2⌋

    Build Algorithms

    • Random (Sequential): O(n log n) — Inserts n elements one by one.
    • Build Heap (Floyd's Algorithm): O(n) — Heapifies subtrees bottom-up from the last non-leaf node down to index 0.

    Tips & Keyboard Shortcuts

    • Batch Insert: Enter comma-separated numbers (e.g., 10, 4, 15, 2, 8).
    • Interactive Dual View: Hovering any tree node highlights its array cell (and vice versa) and shows its index, parent, and child indices.
    • Shortcuts: Enter Insert, Space Pause/Resume, ←/→ Step Back/Forward, Ctrl+Z Undo, Esc Close Help.
