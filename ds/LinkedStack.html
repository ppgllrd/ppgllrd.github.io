LinkedStack

Step-by-step semantics

Step-by-step stops only at real Java LinkedStack actions: creating node objects, updating top, updating size, assigning next references, reading the top element reference, variables going out of scope when a method returns, and explicitly noting when an object has become unreachable and may later be reclaimed by the garbage collector.

Highlight-only preparation steps are merged into the actual semantic update step. Purely visual rearrangements run automatically, show no status message, and do not wait for Next step. When a node is crossed out, that same non-visual semantic step states that the node is unreachable and that the Java garbage collector may reclaim it later, including in Clear.

A LinkedStack stores elements using a Last-In-First-Out (LIFO) policy. The most recently pushed element is the first one returned by pop or top.

This is a Java-style reference/object visualization. A field or local variable contains a reference to an object, or null. The stack object stores top, a reference to the top node object, and size, the number of stored elements.

Each node object has an element field and a next field. Because the structure is generic, node.element is a reference to a value object, not necessarily a primitive stored inside the node.

An object is reachable if it can be reached by following references from active variables or fields. When no active reference can reach a node object, it is an unreachable object and the Java garbage collector may eventually reclaim it.

Data-structure operations and asymptotic complexity

  • Push: creates a node object, sets its next field to the former top node, updates top, and increments size. Complexity: O(1).
  • Pop: updates top to the second node, decrements size, and returns the former top element reference. The former top node becomes unreachable from the stack. Complexity: O(1).
  • Top: reads and returns the element reference stored in the top node without removing it. Complexity: O(1).
  • Clear: sets top to null and sets size to 0. The former node chain becomes unreachable from the stack. Complexity: O(1) for the logical operation; garbage collection is handled by the runtime.

Step-by-step execution and navigation

Turn Step-by-step on to make only non-visual Java LinkedStack steps wait for Next step. Turn it off to let animations advance automatically. The canvas supports mouse wheel zoom, mouse dragging, and touch panning/pinch zoom.
