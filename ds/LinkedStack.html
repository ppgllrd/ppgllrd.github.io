    LinkedStack

    Data Structure

    A LinkedStack stores elements using a Last-In-First-Out (LIFO) policy. The most recently pushed element is the first one returned by top.

    This is a Java-style reference/object visualization: the stack object stores top (a reference to the top node object) and size. Each node object has an element reference to a value object and a next reference. Unreachable nodes become eligible for Java garbage collection.

    Operations & Complexity

    • Push: Creates a node, sets newNode.next = top, updates top = newNode, and increments size — O(1)
    • Pop: Updates top = top.next and decrements size; the unlinked node becomes unreachable for GC — O(1)
    • Top: Reads the element reference of the node referenced by top — O(1)
    • Clear / Empty: Sets top = null and size = 0 — O(1)

    Tips & Keyboard Shortcuts

    • Mouse / Touch: Drag to pan, scroll wheel or pinch to zoom, click/tap any node to copy its value into Element, hover to inspect fields.
    • Shortcuts: Enter in Element pushes, Space Pause/Resume/Next, ←/→ Step Back/Forward, Ctrl+Z Undo, Esc Close Help.
