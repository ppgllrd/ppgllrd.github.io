    Separate Chaining Hash Table

    Concept

    Separate Chaining resolves collisions by maintaining a linked list of nodes at each array index. Before inserting, if loadFactor() > maxLoadFactor, the table rehashes to the next prime > 2 * capacity.

    Hash Function (Java-style)

    • Integers (e.g. 42): (42 & 0x7fffffff) mod capacity
    • Single Characters (e.g. A): ASCII('A') mod capacity
    • Strings (e.g. cat): Java String.hashCode() (polynomial base 31) masked with 0x7fffffff mod capacity

    Operations & Complexity

    • Insert O(1) avg — Checks loadFactor() > maxLoadFactor (rehashes if exceeded, O(n)), then searches the chain using Finder. If absent, inserts at the head. If already present, updates finder.current.key = key (highlighted in amber).
    • Search O(1) avg — Traverses the chain at hash(key). Expected steps depend on α.
    • Delete O(1) avg — Finds the node via Finder and unlinks it from the chain.

    Tips & Keyboard Shortcuts

    • Batch Insert / Delete: Enter comma-separated keys (e.g., A, B, 42, 17).
    • Shortcuts: Enter Insert, Space Pause/Resume, ←/→ Step Back/Forward, Ctrl+Z Undo, Esc Close Help.
