    SortedArraySet

    A SortedArraySet stores unique elements in sorted order in an internal array of references elements. The object tracks size; the capacity is the length of the internal array.

    Operations

    • Insert: Binary-searches the element. If not found, uses the insertion point and shifts references right to keep the set sorted. Complexity: O(log n) search + O(n) shifting (and O(n) on reallocation).
    • Delete: Binary-searches the element. If found, shifts following references left and sets the old last slot to null. Complexity: O(log n) search + O(n) shifting.
    • Contains: Binary-search membership test. Complexity: O(log n).
    • Iterate: Visits elements in sorted order from index 0 to size - 1. Complexity: O(n).
    • Empty: Creates a new empty sorted set with the selected initial capacity.
    • Clear: Sets used array references to null and sets size to 0, keeping the allocated array. Complexity: O(n).
    • Union / Intersection / Difference: Merge-traverses two sorted sets using elem1 and elem2. Complexity: O(n + m).
    • Ensure Capacity: When full, Arrays.copyOf allocates a doubled array and copies the references. Complexity: O(n).

    Finder and Iterator

    The Finder object holds only found and index. During binary search, left, right, and mid appear as animated local variables.

    The iterator stores currentIndex; each step visits the element and increments it until reaching size.

    Tips & Keyboard Shortcuts

    • Batch Insert / Delete: Enter comma-separated integers in Element (e.g., 5, 12, 20).
    • Shortcuts: Enter Insert, Space Pause/Resume, ←/→ Step Back/Forward, Ctrl+Z Undo, Esc Close Help.
