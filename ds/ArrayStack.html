ArrayStack

An ArrayStack stores object references in an internal array elements. The field size is both the number of stored elements and the next free position. The top element is at elements[size - 1].

Operations

  • Push: stores the new reference at elements[size] and increments size. If the array is full, a new array with double capacity is created and all existing elements are copied over before inserting the new one.
  • Top: returns elements[size - 1] without modifying the stack.
  • Pop: sets the top reference to null, so the object may become unreachable and later be reclaimed by Java's garbage collector, and decrements size.
  • isEmpty: checks whether size == 0.
  • Size: returns the current value of size.
  • Empty: creates a new empty stack with the chosen initial capacity.
  • Clear: sets all used references to null, so the objects may become unreachable and later be reclaimed by Java's garbage collector, and resets size to 0.
  • Ensure capacity: when full, Arrays.copyOf allocates a larger array and copies the references over. Complexity: O(n).

Complexity summary

  • Push: amortized O(1), O(n) when resizing.
  • Top, Pop, isEmpty, Size: O(1).
  • Clear: O(n) for clearing references.
