    Binary Search Tree (BST)

    Properties

    A rooted binary tree data structure where the key of each internal node is:

    • Greater than all keys in the node's left subtree.
    • Less than all keys in the node's right subtree.

    Complexity

    The time complexity of operations depends on the height h of the tree:

    • Average Case: O(log n) (when roughly balanced).
    • Worst Case: O(n) (when degenerate/skewed, e.g., inserting sorted keys — try the Skewed O(n) button).

    Algorithms

    • Search / Insert / Min / Max: Follow left or right comparisons down from the root.
    • Delete:
      • Leaf: Remove directly.
      • One Child: Replace node with its single child.
      • Two Children: Find inorder successor (minimum of right subtree), copy its value, and delete the successor.

    Tips & Keyboard Shortcuts

    • Batch Insert / Delete: Enter comma-separated numbers (e.g., 50, 30, 70, 20, 40).
    • Mouse / Touch: Drag to pan, scroll wheel or pinch to zoom, click/tap a node to copy its value, hover to inspect depth, height, and subtree size.
    • Shortcuts: Enter Insert, Space Pause/Resume, ←/→ Step Back/Forward, Ctrl+Z Undo, Esc Close Help.
