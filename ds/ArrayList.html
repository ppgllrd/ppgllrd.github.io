ArrayList

A Java ArrayList stores the sequence in a internal array of references elements. The object also tracks size. The capacity is implicitly the length of the internal array.

Iterator

The ArrayListIterator keeps a currentIndex index. It starts at 0; each returned element increments currentIndex. When currentIndex is greater thanor equal to size, iteration is complete.

Data-structure operations and asymptotic complexity

  • Append: ensure capacity, write the object reference at elements[size], then increment size. Complexity: amortized O(1); O(n) in the occasional worst case when reallocation of the array occurs.
  • Prepend: insert at index 0, shifting all current references one position to the right. Complexity: O(n).
  • Insert: shift references from the insertion point to the right, write the new reference, then increment size. Complexity: O(n).
  • Get: direct access to elements[index]. Complexity: O(1).
  • Set: replace the reference at the selected index. Complexity: O(1).
  • Delete: shift elements to the left and explicitly set the last position to null, so the object may become unreachable and later be reclaimed by Java's garbage collector. Complexity: O(n).
  • Iterate: visits the cell elements from indices 0 to size - 1, returning elements in list order. Complexity: O(n) to visit all elements.
  • Clear: iterates the array setting all references to null, so the objects may become unreachable and later be reclaimed by Java's garbage collector, and sets size to 0. Complexity: O(n).
  • Ensure capacity: when full, Arrays.copyOf allocates a larger array and copies the references over. Complexity: O(n).
