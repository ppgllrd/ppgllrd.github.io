    LinkedList (C-Style Memory & Pointers)

    Data Structure

    A singly linked list stores a sequence of values in separate heap-allocated nodes. Each node contains an element field and a p_next reference. The last node has no successor, so its p_next is NULL.

    The list struct stores p_first, p_last, and size. Maintaining p_last makes tail appends and tail accesses O(1).

    Memory Concepts

    • Pointer states: Uninitialized pointer boxes are empty inside; NULL pointers display a centered dot without an arrow; initialized pointers display a centered dot and an arrow to their target node.
    • Reference colors: Blue indicates an idle reference, green highlights a pointer/value being read or traversed (source), and red highlights a pointer/field being written (target).
    • Heap vs. Local stack pointers: Nodes live in heap memory until explicitly freed. Local traversal pointers (p_current, p_previous, p_delete, p_node) go out of scope when the operation returns.
    • Dangling pointer (orange): Stores an address whose node was already freed; accessing it is invalid until cleared or reassigned.

    Operations & Complexity

    • New: Allocates an empty list (NULL, NULL, 0) — O(1).
    • Append / Prepend: Allocates a new node and updates tail or head — O(1).
    • Insert: Traverses to index i and links a new node — O(n) (head/tail O(1)).
    • Get / Set: Traverses to index i (or uses p_last at tail) — O(n) (tail O(1)).
    • Delete: Bypasses node at index i, updates head/tail if needed, and frees memory — O(n).
    • Clear: Traverses and frees every node sequentially, then clears p_first, p_last, and size — O(n).
