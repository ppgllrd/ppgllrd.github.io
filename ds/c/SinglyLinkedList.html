    Singly Linked List (C-Style Memory & Pointers)

    Data Structure

    A singly linked list is a chain of heap-allocated nodes. Each node stores an element field and a p_next pointer (or NULL at the tail). The list itself is represented solely by p_first (a pointer to the first node, or NULL when empty).

    Memory Concepts

    • Pointer states: Uninitialized pointer boxes are empty inside; NULL pointers display a centered dot without an arrow; initialized pointers display a centered dot and an arrow to their target node.
    • Reference colors: Blue indicates an idle reference, green highlights a pointer/value being read or traversed (source), and red highlights a pointer/field being written (target).
    • Heap vs. Local stack pointers: Nodes stay on the heap until explicitly freed. Local pointers (p_current, p_previous, p_last, p_delete, p_node) are deallocated when the operation returns.
    • Dangling pointer (orange): Still holds the address of a freed node; accessing it is invalid until reassigned or cleared.

    Operations & Complexity

    • New: Empty list (p_first = NULL) — O(1).
    • Prepend: Allocates node and updates p_first — O(1).
    • Append: Traverses from p_first to the tail with p_last and links the new node — O(n).
    • Insert / Sorted Insert / Delete: Traverses with p_previous and p_current and updates links — O(n).
    • Get / Set / Size: Traverses from p_first to index i or NULL — O(n).
    • Clear: Frees every heap node sequentially, then sets p_first = NULL — O(n).

    Tips & Keyboard Shortcuts

    • Mouse / Touch: Drag to pan, scroll wheel or pinch to zoom, click/tap any node to populate Value & Index, hover to inspect node details.
    • Step-by-step Mode: Runs layout transitions automatically and pauses at every real C-pointer algorithm step (advance with Space, →, Next, or >|).
    • Shortcuts: Enter in Value appends (in Index inserts/gets), Space Pause/Resume/Next, ←/→ Step Back/Forward, Ctrl+Z Undo, Esc Close Help.
