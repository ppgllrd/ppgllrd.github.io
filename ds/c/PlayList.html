PlayList

A doubly linked list of songs. Each heap node stores songName, p_prev, and p_next. The playlist object stores p_first and p_playing.

The animation follows the supplied C implementation, including local traversal pointers, link updates, allocation, freeing, dangling references, and the movement of p_playing.

  • Insert front/end/in order, insert before/after
  • Delete front or a named song
  • Move playing song forward/backward
  • Print, sort, delete all, create a new list

Red circles mark the field being changed. A red cross marks freed memory or a local variable leaving scope. Orange arrows are dangling references.
