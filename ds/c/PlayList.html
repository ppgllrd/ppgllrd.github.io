Doubly linked playlist

The playlist is implemented as a doubly linked list. Each node stores a song name, a pointer to the previous node, and a pointer to the next node. The playlist stores pointers to the first node and the currently playing node.

  • Insert front: adds a song at the beginning. O(1).
  • Insert end: traverses the list and adds a song at the end. O(n).
  • Insert in order: assumes an initial sorted list, finds the right position for keeping list sorted and inserts the song. O(n).
  • Insert after: finds the target song and inserts after it. O(n).
  • Insert before: finds the target song and inserts before it. O(n).
  • Delete front: removes the first song. O(1).
  • Delete song: finds and removes a named song. O(n).
  • Previous: moves the playing pointer to the previous node. O(1).
  • Next: moves the playing pointer to the next node. O(1).
  • Playing song: reads the current song. O(1).
  • Print: traverses and displays every song. O(n).
  • Sort: bubble-sorts song names by repeated traversals. O(n²) worst case.
  • Delete all: frees every node. O(n).
  • New: creates an empty playlist. O(1).
  • Build random: creates a random playlist with n songs. O(n).
