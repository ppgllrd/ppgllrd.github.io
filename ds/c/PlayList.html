    Doubly Linked PlayList

    Data Structure

    The playlist is implemented as a doubly linked list. Each node stores a songName, a p_prev pointer to the preceding node, and a p_next pointer to the following node. The PlayList struct stores p_first and p_playing.

    Operations & Complexity

    • Insert front / Delete front: O(1)
    • Insert end / Insert in order / Insert after / Insert before / Delete song: O(n)
    • Previous / Next / Playing song: O(1)
    • Print / Delete all / Build random: O(n)
    • Sort: Bubble-sorts song names by repeated traversals — O(n²) worst case.
    • New: Creates an empty playlist — O(1).

    Tips & Keyboard Shortcuts

    • Mouse / Touch: Drag to pan, scroll wheel or pinch to zoom, click/tap any node to copy its song into Target, hover to inspect neighbours.
    • Shortcuts: Enter in Song inserts at end, Space Pause/Resume/Next, ←/→ Step Back/Forward, Ctrl+Z Undo, Esc Close Help.
