    Weighted Round Robin Scheduler

    Data Structure

    The scheduler is a singly linked circular list. Each node embeds a task (id, name, and quantum) and a p_next pointer to the following node. The scheduler stores only p_last; the first node is p_last->p_next.

    Operations & Complexity

    • Enqueue: Inserts a copied task at the end — O(1)
    • First: Returns an independent copy of the first task — O(1)
    • Dequeue: Removes the first node — O(1)
    • Run first: Simulates one WRR turn by advancing p_last to p_last->p_next — O(1)
    • Size / Print / Clear: Traverses the circular list — O(n)
    • New: Creates an empty scheduler (p_last = NULL) — O(1)

    Tips & Keyboard Shortcuts

    • Mouse / Touch: Drag to pan, scroll wheel or pinch to zoom, click/tap any node to copy its fields into the input boxes, hover to inspect p_next.
    • Shortcuts: Enter in any task field enqueues the task, Space Pause/Resume/Next, ←/→ Step Back/Forward, Ctrl+Z Undo, Esc Close Help.
