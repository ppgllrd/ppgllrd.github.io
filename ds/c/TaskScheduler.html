Weighted Round Robin Scheduler

Data structure

The scheduler is a singly linked circular list. Each node embeds a task and a pointer to the next node. The scheduler stores only p_last; the first node is p_last->p_next.

The yellow fields reproduce the task layout from the assignment: id, name, and quantum. Cyan fields are node pointers.

Operations

  • Enqueue: inserts a copied task at the end in O(1).
  • First: returns an independent copy of the first task in O(1).
  • Dequeue: removes the first node in O(1).
  • Run first: simulates one WRR turn by moving the first task to the back after its quantum.
  • Size and Clear: traverse the circle in O(n).
