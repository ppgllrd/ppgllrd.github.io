    ArrayList (Dynamic Contiguous Array)

    Data Structure

    An ArrayList stores a logical sequence inside a contiguous heap-allocated array. The struct stores elements (pointer to the backing array), capacity (total allocated cells), and size (number of logical elements).

    Cells 0 .. size - 1 are active logical elements. Cells size .. capacity - 1 are allocated memory outside the logical list; they may retain stale physical values until overwritten.

    Operations & Complexity

    • New: Allocates an empty ArrayList with chosen capacity (size = 0) — O(1) metadata (+ array allocation).
    • Get / Set: Direct indexed array access elements[i] — O(1).
    • Append: Ensures capacity, writes at elements[size], increments size — amortized O(1), worst-case O(n) on resize.
    • Prepend / Insert: Shifts elements right from the back to index i, writes value, increments size — O(n).
    • Delete: Shifts elements after index i left by 1, decrements size — O(n) (O(1) at tail).
    • Clear: Sets size = 0 while keeping the allocated backing array and capacity — O(1).
    • Resize (Double Capacity): Allocates a 2× array, copies existing elements, updates elements and capacity, and releases the old array — O(n).
