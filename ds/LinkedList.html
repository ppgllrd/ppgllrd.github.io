    LinkedList

    Data Structure

    A LinkedList stores an ordered sequence of elements as node objects connected by references. Each node has an element field and a next field. The list object stores first, last, and size.

    This is a Java-style reference/object visualization: a field or local variable holds a reference to an object or null. An object is reachable while active references can reach it; once unlinked from all active references, it becomes eligible for Java garbage collection.

    Iterator

    The LinkedListIterator keeps a current reference starting at first. Each step returns the referenced element and advances current to current.next until current == null.

    Operations & Complexity

    • Append / Prepend: Inserts at the end or beginning — O(1)
    • Insert / Delete: Inserts or removes at index — O(n)
    • Get / Set: Accesses or replaces element at index — O(n) (O(1) for last index via last)
    • Iterate: Visits every element with LinkedListIterator — O(n)
    • Clear / Empty: Sets first = null, last = null, size = 0 — O(1)

    Tips & Keyboard Shortcuts

    • Mouse / Touch: Drag to pan, scroll wheel or pinch to zoom, click/tap any node to copy its Element & Index into inputs, hover to inspect fields.
    • Shortcuts: Enter in Element appends, Space Pause/Resume/Next, ←/→ Step Back/Forward, Ctrl+Z Undo, Esc Close Help.
